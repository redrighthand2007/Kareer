## ✨ Features

- **Me-Centered Core Loop:** Connects your identity to your target role by mapping out skills, gaps, and roadmaps.
- **Unified Professional Identity:** Track education, interests, and professional history in one place.
- **Skill & Evidence Tracking:** Log your skills and immediately attach concrete evidence (projects, certificates).
- **Target Role Mapping:** Explore possible career paths, compare them, and define a clear target role.
- **Personalized Roadmaps:** Identify skill gaps and generate a step-by-step roadmap to bridge them.
- **End-to-End Application Tracking:** Log opportunities, manage job applications, and prepare for interviews all within the same ecosystem.
- **100% Client-Side:** Blazing fast Vanilla JS Single Page Application (SPA) with local browser storage.

## 🎯 Why This Project?

**The Problem:** A student's professional information is normally scattered across dozens of platforms: GitHub, LinkedIn, resume files, certificates, course platforms, DSA websites, project folders, Notes apps, and messy job spreadsheets.

**The Solution:** **Kareer** brings all of this together into one connected system. Instead of asking "What careers exist?", Kareer asks: *"Where am I, where do I want to go, what am I missing, and what should I do next?"* It acts as a personal Career OS that turns scattered data into an actionable professional roadmap.

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+)
- **Backend:** None (100% Client-Side architecture)
- **Database:** Local Browser Storage (`localStorage` / `IndexedDB`)
- **Architecture:** Custom Vanilla JS SPA / Hash Router
- **Deployment:** GitHub Pages (Planned)

## 🧠 How It Works

Kareer relies on a strict **"Me-Centered" Core Loop**:

```text
ME ➔ PROFILE ➔ SKILLS ➔ EVIDENCE ➔ PROJECTS ➔ TARGET ROLE ➔ SKILL GAPS ➔ ROADMAP ➔ LEARNING ➔ OPPORTUNITIES ➔ APPLICATIONS ➔ INTERVIEWS ➔ PROGRESS ➔ ME
```

This fundamental architecture ensures every feature serves the ultimate goal of progressing the student's career. The application handles state changes dynamically via modular JavaScript files without ever triggering a full page reload.
